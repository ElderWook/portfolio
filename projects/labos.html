Homelab fleet control plane
SPEC SHEETGitHub ↗

A monorepo and CLI that runs my homelab as one system: four devices across five OS installs on a Tailscale mesh, kept in git-parity from a single source of truth, with encrypted key backups and an always-on hub for wake-on-LAN and exit-node routing.

Specifications
Devices4 physical · 5 OS installs
CLI~2,700 lines of Bash
Automation~17 systemd units
Parityfast-forward-only, 3 triggers
TransportTailscale mesh + Wake-on-LAN
BackupsGPG, private key offline on LUKS USB
Notes
  • A ~2,700-line Bash CLI keeps every machine in fast-forward-only git parity — dirty clones are flagged, never clobbered
  • Self-heals on push, on boot, and on a timer, over keyless Tailscale SSH
  • ~17 systemd units run parity catch-up, a fail-closed VPN leak-guard, wake-on-LAN, and log capture
  • An always-on Orange Pi hub: Tailscale exit node, subnet router, and wake-on-LAN relay
  • Encrypted GPG key backups, with the private key kept offline on a LUKS USB
