⏚ labos

Homelab fleet control plane
SPEC SHEETGitHub ↗

Infrastructure-as-code for a personal homelab: a monorepo and CLI that treat a fleet of machines as one reproducible, disaster-recoverable system. Every environment is defined in code and kept converged from a single source of truth, with encrypted-at-rest key management.

Specifications
Scopewhole-homelab config-as-code
CLI~2,700 lines of Bash, from scratch
Automation~17 systemd units
Convergencegit parity, fast-forward-only
CoverageLinux, Windows, and ARM environments
Key managementGPG-encrypted at rest, key offline
Notes
  • A ~2,700-line Bash CLI manages the whole fleet from one source of truth
  • Git-parity convergence — fast-forward-only, so a dirty working tree is always flagged, never clobbered
  • Self-healing automation: systemd units run parity catch-up, log capture, and cleanup on a schedule
  • Every environment defined as code — Ansible recipes plus stowed dotfiles — so any machine rebuilds from scratch
  • Encrypted-at-rest key management: every secret is a GPG-encrypted blob, private key kept offline
