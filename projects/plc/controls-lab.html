A virtualized industrial-controls lab on Arch Linux — a Dockerized SCADA/IIoT stack, an ESP32 Modbus I/O node, and IEC 61131-3 Structured Text, all built from scratch.

Notes
  • A full SCADA/IIoT stack in Docker: Ignition, OpenPLC, Node-RED, MQTT, and a Postgres historian
  • An ESP32 flashed as a Modbus TCP I/O node — buttons, relays, LEDs, and analog-in on a real bench
  • A reversing motor starter in Structured Text: seal-in, interlock, anti-plug, dual overload, first-out fault
  • A reproducible golden→clone Windows-VM workflow for the vendor IDEs, codified in libvirt
  • Real infra debugging — a ufw/Docker/libvirt conflict dropping VM traffic, a dnsmasq port collision, TPM + Secure Boot
  • Rounded out by a documented 240V panel design (on paper) and bench firmware still awaiting hardware bring-up
