Notes
  • Strict pure-core architecture — all site rendering is string->string with zero Tauri/Svelte/DOM in the core, guarded by a 200+ test suite
  • A WYSIWYG Studio with a per-element CSS inspector, hover/focus/active states, and responsive per-breakpoint edits driven by a live style-rule engine
  • A durable theme system — the palette lives in the site's JSON, so it survives restarts and republishes — plus reusable components, data-URI image embedding, and a viewport switcher
